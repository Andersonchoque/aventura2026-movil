# Aventura Pixel 2026

Juego de Anderson para Alejandra, con cuatro niveles, enemigos, estrellas de inmunidad y música final.

## Jugar
Abre el enlace de GitHub Pages en Safari (iPhone), Chrome (Android) o un navegador de escritorio. Pulsa COMENZAR. En el teléfono usa los botones táctiles; se recomienda girarlo horizontalmente. El sonido se activa tras tocar la pantalla.

PC: flechas o A/D para moverse, Espacio/W para saltar y P para pausar.

## Publicación
GitHub Settings → Pages → Deploy from a branch → main → / (root).

No requiere instalar dependencias. Se conserva el archivo de audio incluido en el proyecto original.
